Prisma para Windows 1.0.1
=========================

Prisma lee en voz alta las respuestas de Codex, Claude Code y OpenCode, y
muestra un orbe animado mientras habla. La app vive en la bandeja del sistema
y se configura desde Ajustes.

Requisitos
----------

- Windows 10 u 11 de 64 bits, con salida de audio y una sesión gráfica.
- Python 3.11 o 3.12 de 64 bits, con Tkinter, pip y el lanzador "py".
  Comprueba con:  py -3 --version   y   py -3 -m tkinter
- PowerShell, conexión a internet y, si quieres instalar desde el código,
  Git. Edge necesita internet para cada síntesis; Piper y la voz de Windows
  funcionan sin conexión.
- Codex, Claude Code u OpenCode instalados de forma nativa en Windows.
  WSL y los contenedores usan otras rutas y procesos; esta instalación no
  conecta sus hooks con la app de Windows.

Instalación desde este ZIP
--------------------------

1. Descomprime el ZIP en una carpeta, por ejemplo en el Escritorio.
2. Abre la carpeta Prisma y haz doble clic en "Instalar Prisma.cmd".
3. Si Windows SmartScreen avisa, elige "Más información" y "Ejecutar de
   todos modos". El instalador solo ejecuta los archivos de esta carpeta.
4. Espera a que cree el entorno y descargue las dependencias y la voz
   Piper. La primera instalación puede tardar varios minutos.
5. Al terminar se crea un acceso en el menú Inicio y Prisma se abre en la
   bandeja del sistema.

El instalador guarda la app, el entorno, la voz, los ajustes y los registros
en %LOCALAPPDATA%\Prisma. No necesita permisos de administrador.

Conectar los agentes
--------------------

El instalador configura los agentes que encuentra. Para conectar, reconectar
o desconectar cualquiera de ellos:

1. Haz clic derecho en el icono de Prisma en la bandeja.
2. Elige "Ajustes".
3. En la sección "Agentes", pulsa "Conectar" junto a Codex, Claude Code u
   OpenCode.

Prisma instala sus hooks e instrucciones en tu carpeta de usuario
(%USERPROFILE%\.codex, %USERPROFILE%\.claude o la configuración de OpenCode)
sin depender de esta carpeta. Solo necesita que la CLI del agente esté
instalada. Si falta, la fila lo indica. Estas conexiones valen para sesiones
locales en este PC: las sesiones en la nube, en WSL, en contenedores o en
otro equipo no ejecutan estos hooks.

"Desconectar" elimina únicamente los cambios de Prisma y conserva el resto
de la configuración del agente. Reinicia las sesiones abiertas para que
carguen los hooks nuevos.

Codex puede pedirte que autorices sus hooks. Prisma intenta marcarlos como
confiables mediante el protocolo de Codex; si no lo consigue, ábrelo y
acéptalos cuando lo pregunte.

Probar la voz
-------------

En el menú de la bandeja elige "Probar voz". También puedes ejecutar, desde
la carpeta Prisma:

  powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\test.ps1

  powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\test.ps1 -Text "Hola, soy Dalia." -Voice dalia

  powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\test.ps1 -Engine piper

  powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\test.ps1 -Engine windows

En Ajustes puedes cambiar el motor, la voz de Edge, el modo de lectura, la
velocidad, la posición del orbe, la visibilidad y la atenuación del audio de
fondo.

Problemas frecuentes
--------------------

- No aparece el icono: busca Prisma en el menú Inicio y revisa los iconos
  ocultos de la bandeja. El registro está en
  %LOCALAPPDATA%\Prisma\prisma.log.
- La app habla pero el agente no avisa: reinicia el agente, revisa que sus
  hooks estén activos y vuelve a conectarlo desde Ajustes. El registro de
  los hooks está en %LOCALAPPDATA%\Prisma\hook.log.
- Edge no suena: comprueba la conexión o elige Piper o la voz de Windows.
  Piper necesita el modelo .onnx y su archivo .onnx.json.
- No se restauró el volumen de otra app: revísalo en el mezclador de
  Windows o desactiva la atenuación en Ajustes.
- El instalador no encuentra Python o Tkinter: instala Python 3.11 o 3.12
  de 64 bits con Tkinter y comprueba que "py -3 -m tkinter" abre una
  ventana.

Privacidad
----------

El servidor local escucha solo en 127.0.0.1, usa un puerto entre 8787 y
8798 y exige un token para hablar o detenerse. Edge envía el texto a su
servicio de síntesis; Piper y la voz de Windows son locales. El instalador
descarga dependencias y el modelo de voz desde internet.

Validación
----------

Esta versión para Windows es nueva y todavía necesita validación de extremo
a extremo en un equipo Windows real. Las pruebas automatizadas cubren el
protocolo local, los hooks y la conexión de los tres agentes, pero no
sustituyen una prueba con las CLI y el audio reales. Si algo falla, los
registros de %LOCALAPPDATA%\Prisma ayudan a diagnosticarlo.
